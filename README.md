# StudyTrack AI

MVP funcional de estudo adaptativo para vestibulares.

## Funcionalidades

- Dashboard de desempenho e prioridades
- Cadastro e metas para vários vestibulares
- Correção de simulados com respostas e gabarito
- Diagnóstico por matéria, assunto e subassunto
- Caderno de erros e treino adaptativo
- Banco de questões com filtros, questões salvas e páginas originais
- Autenticação e persistência por usuário
- Interface responsiva com modo claro e escuro

## Stack

Next.js/Vinext, React, TypeScript, CSS e Cloudflare D1 via OpenAI Sites.

## Desenvolvimento

```bash
npm install
npm run dev
```

Não adicione chaves, senhas ou arquivos `.env` ao repositório.
